# EXION Expense Workspace 8

ระบบเบิกค่าใช้จ่ายภาษาไทยสำหรับคอมพิวเตอร์และมือถือ ใช้ HTML/CSS/JavaScript กับ Google Apps Script และ Google Sheets เดิม

## สิ่งที่ปรับปรุง

- หน้าภาพรวมใหม่: ยอดค่าใช้จ่าย งานที่ต้องทำ และทางลัดไปคำขอ
- ฟอร์มหลายรายการ: เก็บร่างพร้อมใบเสร็จใน IndexedDB, ตรวจข้อมูล, ตรวจยอดก่อนส่ง และใช้รหัสชุดเดิมเมื่อส่งซ้ำหลังเน็ตหลุด
- เมนูด้านข้างบนคอมพิวเตอร์ เมนูด้านล่างและปุ่มตรวจสอบยอดบนมือถือ
- ศูนย์งานอนุมัติ และหน้ารอบเบิก/การจ่ายเงิน แยกจากบัญชีและลายเซ็น
- เซสชันที่เซิร์ฟเวอร์ลงนาม ตรวจสิทธิ์ผู้ดำเนินการ และรหัสตั้งบัญชีแบบใช้ครั้งเดียว
- จัดเตรียมรายการในฝั่งเซิร์ฟเวอร์ก่อนเขียนหลายแถว ลดการบันทึกเพียงบางรายการเมื่ออัปโหลดใบเสร็จไม่สำเร็จ
- ฟอนต์ Kanit อยู่ในโปรเจกต์ พร้อมใบอนุญาตใน `fonts/OFL.txt`

## เริ่มใช้งาน

อ่าน [คู่มือติดตั้ง](docs/DEPLOYMENT.md) ก่อนอัปโหลด ต้องอัปเดต backend และหน้าเว็บเป็นรุ่น 8 คู่กัน หน้าเว็บรุ่นนี้ใช้กับ backend เก่าไม่ได้

- Frontend: ไฟล์ HTML ที่รากโปรเจกต์ พร้อม `css/`, `js/`, `icons/`, `fonts/`, `manifest.json`, `service-worker.js`
- Backend: นำ `backend/Code.gs` และ `backend/Auth.gs` ไปไว้ใน Apps Script โปรเจกต์เดียวกัน
- API endpoint: ตั้งใน `js/config.js` หลังเตรียม Apps Script เรียบร้อย

ชุดนี้ยังไม่ได้เผยแพร่ขึ้นระบบจริง ผลการตรวจสอบใช้ Google services และ API จำลอง อ่านรายละเอียดใน [ผลทดสอบและรายการตรวจรับ](docs/QA.md)

## ทดสอบในเครื่อง

ต้องมี Node.js 20 ขึ้นไป สำหรับการตรวจ syntax และ backend ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```sh
node tests/syntax.cjs
node tests/backend.cjs
npm install
npx playwright install chromium
node tests/browser.cjs
```

Browser test เปิดเซิร์ฟเวอร์ทดสอบที่ `127.0.0.1:8765` ภายในสคริปต์ ใช้ข้อมูลจำลองและดัก API ไม่ส่งคำขอไปยัง Apps Script จริง สร้างภาพหน้าจอและผลตรวจใน `tests/artifacts/`

หากต้องการเปิดหน้าเว็บต่อ backend ที่ตั้งค่าแล้ว ใช้ `python -m http.server 8000` และเปิด `http://localhost:8000` ไม่ควรเปิดผ่าน `file://` เพราะการเก็บร่างและ PWA ต้องใช้ HTTP localhost หรือ HTTPS
