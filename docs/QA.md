# ผลตรวจสอบ Workspace 8

ตรวจวันที่ 22 กันยายน 2026 ภายในสภาพแวดล้อมพัฒนา ไม่มีการเรียก Apps Script production หรือเขียนข้อมูลจริง

| การตรวจ | ผล |
|---|---|
| JavaScript / Apps Script / inline script และลิงก์ JS/CSS ภายใน | ผ่าน 34 scripts |
| Backend behavior ผ่าน Google services จำลอง | ผ่าน 15 กรณี |
| Chromium desktop 1440 px | ผ่าน 24 routes ไม่พบ page exception หรือหน้าเลื่อนล้นแนวนอน |
| Chromium mobile viewport 390 px | ผ่าน 7 routes ไม่พบ page exception หรือหน้าเลื่อนล้นแนวนอน |
| สร้างค่าใช้จ่าย แนบใบเสร็จ reload กู้ร่าง ตรวจช่องว่าง ทบทวนยอด ส่งสำเร็จ | ผ่าน API จำลอง |
| เน็ตหลุดระหว่างส่ง → reload → ข้อมูลถูกล็อก → ส่งซ้ำ | ใบเสร็จยังอยู่และ payload/BatchID ตรงกับครั้งแรก |
| Login และเก็บเซสชันจากเซิร์ฟเวอร์ | ผ่าน API จำลอง |
| ข้อความ HTML ในช่องรายละเอียด | แสดงเป็นข้อความ ไม่รัน payload ที่ทดสอบ |

Backend tests ครอบคลุม token ปลอม/หมดอายุ/ถูกเพิกถอน, ปิดบัญชี, ปฏิเสธ shared secret เดิม, ปลอมผู้ดำเนินการ, ขอบเขตข้อมูลทีม, ผู้รับประโยชน์เงินสดย่อย, เหตุผลไม่อนุมัติ, ข้อจำกัดไฟล์, รหัสตั้งบัญชีใช้ครั้งเดียว, rate limit, อัปโหลดล้มเหลวไม่เขียนบางแถว, การเขียนชุดเดียว, ส่งซ้ำคืนผลเดิม และใบเสร็จที่จำเป็น

ภาพหน้าจอใน `tests/artifacts/` ใช้ชื่อและยอดตัวอย่าง ไม่ใช่ข้อมูลบริษัทจริง การตรวจ route เป็น smoke test ไม่ได้กดทุกฟังก์ชันในทุกหน้า

## รายการตรวจรับบน staging ที่ยังต้องทำ

| ผู้ทดสอบ / งาน | เกณฑ์ผ่าน |
|---|---|
| พนักงาน | เข้าระบบเดิมได้ ตั้งบัญชีใหม่ด้วย code ได้ ไม่อ่านข้อมูลผู้อื่น |
| พนักงาน / ค่าใช้จ่าย | ประเภทตาม Categories จริง แนบ JPG/PDF ได้ เงิน/วันที่/Job ลงชีทครบ |
| พนักงาน / ค่าน้ำมัน | อัตราตามแผนกและรอบวันที่ตรงกับ FuelRates และราคาที่ระบบใช้ |
| หัวหน้า | เห็นเฉพาะสิทธิ์ของทีม อนุมัติ/ปฏิเสธพร้อมเหตุผล กดซ้ำไม่เปลี่ยนสถานะซ้ำ |
| ผู้บริหาร | เห็นกล่องงานและคำขอรอบเบิกตามสิทธิ์จริง |
| บัญชี | เห็นรอบอนุมัติรอจ่าย บันทึกจ่ายแล้วสถานะพนักงานเปลี่ยนถูกต้อง |
| เงินสดย่อย | ขอ อนุมัติ จ่าย ยกเลิก เติมเงิน ตรวจยอด และ MSBC ตรงกับสมุดเงินสด |
| ค่ารับรอง/กอล์ฟ | ขออนุมัติงบ → อนุมัติ → ส่งยอดจริง/ใบเสร็จ → ไม่สร้าง claim ซ้ำ |
| PDF และลายเซ็น | Upload/download ทำงาน ไฟล์มีรายการ/ยอด/ผู้ลงนามครบตาม template จริง |
| Google Drive | ผู้มีสิทธิ์อ่านใบเสร็จได้ ตรวจนโยบายการแชร์ URL ไฟล์เดิมด้วย |
| iPhone/Safari, Android จริง | คีย์บอร์ด กล้อง PDF การเก็บร่าง และเมนูล่างใช้ได้ |
| PWA อัปเกรด/ออฟไลน์ | สลับ cache หลังปิดแท็บ แสดงออฟไลน์และไม่ส่งข้อมูลเบื้องหลัง |
| Backup/trigger | สำรองและกู้คืนบนสำเนาได้ ไม่มี trigger ซ้ำหรืออีเมลทดสอบไปพนักงานจริง |

ไม่ใช่ผล audit ความปลอดภัยครบทั้งระบบ และไม่ได้รับรอง load/performance บนชีทขนาดใหญ่ การอนุมัติ การจ่ายเงิน และ exports บน Google จริงต้องผ่านรายการด้านบนก่อนเปิดให้พนักงานใช้
